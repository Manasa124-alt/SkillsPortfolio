Tech Glossary

HTML
HyperText Markup Language, used for creating web pages.It defines elements like headings, paragraphs, images, links, tables, and forms. HTML acts as the skeleton of a website
CSS
Cascading Style Sheets, used for styling web pages.It controls colors, fonts, layouts, spacing, animations, and responsiveness to make websites attractive and user-friendly.
JavaScript
A programming language used to create interactive effects on web pages.It helps in creating features like buttons, sliders, form validation, pop-ups, and real-time updates on websites.
